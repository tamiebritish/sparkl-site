# Archived Sparkl prototype

This directory is archived and unused by the active Neatly website.

The active Neatly application is the HTML, CSS and JavaScript at the repository root, deployed to Vercel. Its setup is documented in the root NEATLY-BOOKINGS.md and NEATLY-BOOKING-FLOW.md files.

The nested sparkl/ application is an older Hamilton prototype. It contains legacy branding, demo data, email-only booking lookup and database assumptions that differ from Neatly's live schema. Its SQL, seed data, dependencies and deployment instructions must not be applied to the Neatly project.

Preserved for reference. Make active Neatly changes at the repository root.
